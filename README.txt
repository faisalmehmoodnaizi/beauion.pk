BEAUSION.PK WEBSITE

Files:
- index.html: main website
- style.css: responsive design
- script.js: WhatsApp ordering, filters and mobile menu
- assets/: your supplied promotional images

HOW TO USE
1. Extract the ZIP.
2. Open index.html in a browser.
3. To use your own WhatsApp number, open script.js and change WHATSAPP_NUMBER to your number in international format without + (example: 923001234567).
4. Upload the complete folder to GitHub Pages, Netlify or Vercel.

Note: Prices were not supplied, so the site asks customers to contact WhatsApp for current price and availability.
